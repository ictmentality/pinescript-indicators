Weekly Cycle Requirements (QTEngine)

## Scope
- Instrument/session model: CME equity index futures (ES1!) using Globex daily open at 18:00 America/New_York.
- Goal: week segmentation with daily 18:00 boundaries, holiday-safe, no bar_index anchoring.
- Data-first: timestamps + OHLC + flags only (no drawings/styling).

## Definitions
Timezone: America/New_York for all weekly-cycle timestamps.

For any boundary:
- ts_intent = scheduled boundary time (e.g., 18:00).
- ts_eff = first printed bar-open time on/after ts_intent.

This effective rule is what handles holidays and no-bar periods.

## Week start and quarter numbering (W.Q1–W.Q5)
Week start (W.S):
- W.S_intent = Sunday 18:00.
- W.S_eff = first printed bar-open time >= W.S_intent.

Quarter starts (intent):
- Q1_intent = W.S_intent (Sunday 18:00).
- Q2_intent = Monday 18:00.
- Q3_intent = Tuesday 18:00.
- Q4_intent = Wednesday 18:00.
- Q5_intent = Thursday 18:00.

Quarter starts (effective):
- Qx_start_eff = first printed bar-open time >= Qx_start_intent.
- Quarter numbering is sequential (Q1..Q5) and never relabeled on holidays.

Quarter windows:
- Q1 = [Q1_start_eff, Q2_start_eff)
- Q2 = [Q2_start_eff, Q3_start_eff)  -> "True Week Open"
- Q3 = [Q3_start_eff, Q4_start_eff)
- Q4 = [Q4_start_eff, Q5_start_eff)
- Q5 = [Q5_start_eff, W.S_next_eff)

Week start next (Q5 end):
- W.S_next_intent = next Sunday 18:00.
- W.S_next_eff = first printed bar-open time >= W.S_next_intent.

Weekend time is folded into Q5 (no bars expected on CME futures).

## Quarter open price and flags
For each quarter Qx:
- Qx_open = open of the first printed bar whose bar-open time is within the
  quarter window.
- hasData = true once any bar exists in the window.
- openDelayed = true if Qx_start_eff > Qx_start_intent.
- If no bars print inside the window, keep open as na and hasData = false.

Do not backfill an open outside the window.

## State-trigger rule
Quarter boundary is realized when time_close > boundaryTs.

## Edge cases
A) Monday bank holiday (no bars Sunday 18:00 or Monday session open)
- W.S_eff shifts to first printed bar (often Monday 18:00).
- Q1 hasData = false, open = na if no bars in its window.
- Q2 remains the "True Week Open". Do not relabel.

B) Missing midweek 18:00 boundary
- The affected Qx_start_eff shifts forward to first printed bar after closure.
- The quarter window becomes longer; openDelayed = true.

C) Early close Friday
- Q5 still starts at Thursday 18:00.
- If Friday closes early, FriClose_eff uses last printed bar close.
- Q5 hasData = true if any bar printed after Thu 18:00.

D) DST week
- Compute in America/New_York; never hardcode UTC offsets.

## Minimal outputs for Weekly
Week:
- W.S_intent, W.S_eff, W.S_next_intent, W.S_next_eff

Quarters Q1..Q5:
- Qx_start_intent, Qx_start_eff, Qx_end_eff
- Qx_open, hasData, openDelayed

## QTEngine integration notes (requirements)
- Weekly module mirrors fixed-cycle update flow but uses daily 18:00 intent
  boundaries + effective-first-printed bar rules.
- Use existing aligned/cached series packs or chart-TF gap-safe detection for
  effective boundaries; no new request.security calls unless required.
